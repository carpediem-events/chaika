# Carpe Diem — лендинг под 26–27 сентября

Одностраничник-визитка для рассылки по своим каналам. Цель — чтобы человек
написал в Telegram или Instagram Direct и забронировал место.
Кнопки оплаты на сайте нет намеренно (вопросы с налоговой).

## Запуск

```bash
npm install
npm run dev
```

## Правки контента

Весь текст, даты, цены, ссылки и пути к медиа — в одном файле: `src/content.ts`.
Компоненты трогать не нужно. Список недостающих материалов — в `MATERIALS.md`.

Медиа кладём в `public/media/`, путь пишем без ведущего слэша: `media/hero.mp4`.

## Деплой

Пуш в `main` → GitHub Actions собирает и публикует на GitHub Pages
(`.github/workflows/deploy.yml`). Один раз нужно включить в репозитории
Settings → Pages → Source: **GitHub Actions**.

`base` в `vite.config.ts` — относительный (`./`), поэтому работает и на
`carpediem-events.github.io/<repo>/`, и на своём домене.

## Структура

| Секция | Файл | Что делает |
| --- | --- | --- |
| Первый экран | `components/Hero.tsx` | Видео команды + параллакс + первая кнопка |
| Кто мы | `components/About.tsx` | Короткий рассказ и цифры |
| Дедлайн | `components/Urgency.tsx` | Таймер до конца цены 99 €, счётчик мест |
| События | `components/Events.tsx` | 26-е и 27-е, у каждого своя кнопка брони |
| Прошлые встречи | `components/Gallery.tsx` | Горизонтальная лента (на десктопе — с «прилипанием») |
| Финал + футер | `components/Finale.tsx` | Крупная кнопка и контакты |
| Липкая кнопка | `components/StickyCta.tsx` | Висит с блока прошлых встреч до конца |
| Модалка брони | `components/Booking.tsx` | Выбор Telegram / Instagram, текст подставляется сам |

## Отладка

`?static` в dev-режиме отключает инерционный скролл и анимации проявления —
удобно для скриншотов.
