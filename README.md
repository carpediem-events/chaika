# «Больше драмы» — лендинг Carpe Diem × The Chaika

Одностраничник для рассылки по своим каналам: актёрский мастер-класс
«Больше драмы» от театра The Chaika 26 сентября и спектакль «Пушкин и деньги»
27 сентября, München.

Цель — чтобы человек написал в Telegram или Instagram Direct и забронировал
место. Кнопки оплаты на сайте нет намеренно (вопросы с налоговой).

## Запуск

```bash
npm install
npm run dev
```

## Правки контента

Весь текст, даты, цены, ссылки и пути к медиа — в одном файле: `src/content.ts`.
Компоненты трогать не нужно. Список недостающих материалов — в `MATERIALS.md`.

Медиа кладём в `public/media/`, путь пишем без ведущего слэша: `media/hero.mp4`.

## Деплой

Пуш в `main` → GitHub Actions собирает и публикует на GitHub Pages
(`.github/workflows/deploy.yml`). Один раз нужно включить в репозитории
Settings → Pages → Source: **GitHub Actions**.

`base` в `vite.config.ts` — относительный (`./`), поэтому работает и на
`carpediem-events.github.io/<repo>/`, и на своём домене.

## Структура

| Секция | Файл | Что делает |
| --- | --- | --- |
| Первый экран | `components/Hero.tsx` | «Больше драмы», вспышка-параллакс, рисованная стрелка к кнопке |
| Полоса | `components/Band.tsx` | Одна фраза и видео команды, кадр раскрывается на скролле |
| Два дня | `components/Days.tsx` | 26.09 и 27.09, у каждого своя кнопка брони |
| Программа | `components/Program.tsx` | Расписание мастер-класса, описания раскрываются по клику |
| Ведут / для кого | `components/Hosts.tsx` | Алексей и Егор + короткий список «тебе сюда, если» |
| Прошлые встречи | `components/Gallery.tsx` | Горизонтальная лента (на десктопе — с «прилипанием») |
| Финал и футер | `components/Closing.tsx` | Цена, крупная кнопка, контакты |
| Липкая кнопка | `components/StickyCta.tsx` | Висит с блока прошлых встреч до финала |
| Модалка брони | `components/Booking.tsx` | Две кнопки: Telegram (с готовым текстом) и Instagram |
| Декор | `components/Burst.tsx`, `Doodle.tsx` | Фирменная вспышка и рисованные пометки, дорисовываются на скролле |

## Отладка

`?static` в dev-режиме отключает инерционный скролл и анимации появления.
`?static&only=program` рисует одну секцию — удобно для скриншотов.

Dev-сервер поднимается с `--host`, поэтому открывается с телефона в той же
сети: адрес `Network` печатается при старте `npm run dev`.
