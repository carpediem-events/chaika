# Что нужно прислать (чек-лист для Розы)

Кладём файлы в `public/media/`, затем прописываем путь в `src/content.ts`.
Пока путь пустой — на сайте стоит заглушка с подписью, что туда идёт.

## Медиа

- [ ] **Видео на первый экран** — команда машет в камеру. Горизонтальное, без звука,
      8–15 секунд, зацикливается. → `hero.media.src`
      Если горизонтального нет — пришлите вертикальное, обрежу.
- [ ] **Постер к этому видео** (первый кадр, jpg) — показывается, пока видео грузится. → `hero.media.poster`
- [ ] **Фото/видео «Чайки»** — с работы, репетиций. → `events[0].media.src`
- [ ] **Фото/видео со спектаклей** (для 27-го). → `events[1].media.src`
- [ ] **Прошлые мероприятия**, по 1 кадру на карточку: психология, йога, Rury,
      спектакли, команда целиком. → `gallery.items[*].media.src`
- [ ] **Логотип** (svg или png с прозрачным фоном). → `brand.logo`
- [ ] **Картинка для превью ссылки** в Telegram/Instagram, 1200×630. → `public/media/og.jpg`

Формат: фото — jpg/webp, видео — mp4 (h264). Присылайте оригиналы, сожму сам.
